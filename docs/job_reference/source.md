# Public job reference

- **Title:** Computer Vision Engineer - Floor Plan Image to Vector Geometry

The requirement describes software that reads architectural floor-plan images
and exports structured geometry for walls, doors, windows and rooms, accompanied
by a visual overlay and structured data.

This repository is an independent portfolio project. It was not commissioned
by, developed for, or endorsed by the original client, and it uses only public
or reproducibly generated data.
